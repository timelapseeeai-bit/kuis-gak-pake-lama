# kuis-gak-pake-lama
Aplikasi kuis interaktif untuk TikTok LIVE dengan tema luar angkasa. Dilengkapi 500 pertanyaan dari berbagai kategori, timer 10 detik, sistem penilaian otomatis, leaderboard peserta, dan daftar supporter. Dirancang responsif untuk Android serta dapat digunakan sebagai Progressive Web App (PWA).
